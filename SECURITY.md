# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

- Use GitHub's private reporting: open the [Security tab](https://github.com/bts-io/hookforms/security) and choose **Report a vulnerability**.
- Or email support@hookforms.com with "Security" in the subject.

Include the version or commit, the steps to reproduce it and what an attacker could do with it. We will reply within a few days, keep the report private while we work on a fix, and credit you in the release notes unless you would rather not be named.

## Supported versions

Fixes go into the latest release only. Please upgrade to it before reporting.
